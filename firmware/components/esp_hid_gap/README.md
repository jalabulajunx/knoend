# esp_hid_gap

`esp_hid_gap.c` and `esp_hid_gap.h` are copied unchanged from ESP-IDF v5.4.4,
`examples/bluetooth/esp_hid_device/main/` (Espressif Systems, licence: Unlicense OR CC0-1.0).
They set up Bluetooth LE advertising and pairing for a HID device. Do not edit them here; if a
change is needed, wrap it in `main/ble_keyboard.c` instead, so the copy stays checkable with
`diff` against ESP-IDF.
