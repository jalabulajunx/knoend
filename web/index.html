    How editing works
    • While editing, the board shows the keys you edit here, live, instead of following the app in front.
    • A tap on a board key selects it here; it does not run it.
    • To try your keys: Save, then Stop editing, and use the app.

    Key

    Select a key here or tap one on the board.

    Key names

    Write the keys joined with +, the key last: Primary+Shift+P, Ctrl+C, F5, A. Each names a key on the keyboard, not a character: A types a, Shift+A types A.

    Held keys: Primary (⌘ on a Mac, Ctrl elsewhere: use it so the key works on every computer), Ctrl, Shift, Alt (⌥ Option on a Mac), Meta (⌘ / Windows / Super).

    Keys: A-Z, 0-9, F1-F24, .

    Or press Record and then the keys. A few combinations the system keeps for itself (⌘Tab, ⌘Q) cannot be recorded; type those.
