    How editing works
    • While editing, the board shows the keys you edit here, live, instead of following the app in front.
    • A tap on a board key selects it here; it does not run it.
    • To try your keys: Save, then Stop editing, and use the app.
    • Saving makes your own version on top of the recipe or AI draft; Remove my version brings that back.

    Drag a key onto another place to move it.

    Key

    Select a key here or tap one on the board.

    Key names

    Write the keys joined with +, the key last: Primary+Shift+P, Ctrl+C, F5, A. Each names a key on the keyboard, not a character: A types a, Shift+A types A.

    Held keys: Primary (⌘ on a Mac, Ctrl elsewhere: use it so the key works on every computer), Ctrl, Shift, Alt (⌥ Option on a Mac), Meta (⌘ / Windows / Super).

    Keys: A-Z, 0-9, F1-F24, .

    Or press Record and then the keys. A few combinations the system keeps for itself (⌘Tab, ⌘Q) cannot be recorded; type those.

                Wi-Fi (optional)

                Wi-Fi lets the board work wirelessly anywhere on your 2.4 GHz network, away from the USB cable. Your password goes to the board over the USB cable only and is never stored here. If you keep the board plugged into this computer over USB, you can skip this step.

                Wi-Fi network

                The board looks for networks itself. It hears 2.4 GHz only: a network that is 5 GHz only will not appear.

                    All set. The board will appear on the dashboard in a few seconds. Open the dashboard

                    Bluetooth (optional)

                    The board also advertises as a Bluetooth Low Energy keyboard named KnoEnd.

                    • With Bluetooth paired: the board types keyboard shortcuts directly into this computer (or a tablet or phone) over Bluetooth.
                    • Without Bluetooth: this computer's KnoEnd companion types keyboard shortcuts for the board whenever it is connected over USB or Wi-Fi.
                    1. Open this computer's Bluetooth settings.
                    2. Choose to add or pair a new device, then pick KnoEnd.

                    All set. Your board is ready to use. Open the dashboard

                    Assistant
